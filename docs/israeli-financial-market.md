# מיפוי השוק הפיננסי והביטוחי הישראלי — רקע ל-home-tracker

מסמך זה מסביר איך השוק הפיננסי/ביטוחי בישראל בנוי, כרקע למודל הנתונים של
הפרויקט (`src/lib/types.ts`, `data/providers.seed.json`). המטרה: לכסות את כל
סוגי החשבונות/מנויים/ביטוחים שיש למשק בית ישראלי טיפוסי, ולדעת איפה אפשר
בכלל לשלוף עליהם מידע.

## 1. בנקאות ותשלומים

| תחום | גופים עיקריים |
|---|---|
| בנקים מסחריים | הפועלים, לאומי, דיסקונט, מזרחי-טפחות, הבינלאומי, יהב, אוצר החייל, מרכנתיל |
| בנקים דיגיטליים | ONE ZERO, אש בנק (Esh) |
| כרטיסי אשראי (נפרדו מהבנקים ב"חוק שטרום") | ישראכרט, כאל (Cal), מקס (Max) |

**רגולטור:** בנק ישראל. מ-2021 קיים **חוק שירותי מידע פיננסיים ("Open
Banking" ישראלי)** — מאפשר לגופים מורשים לשלוף נתוני עו"ש/אשראי בהסכמת
הלקוח, דרך API מפוקח. לא ריאלי לפרויקט בית פרטי (דורש רישוי), אבל שווה
לדעת שהוא קיים.

## 2. חיסכון ארוך טווח ופנסיה

| מוצר | מהות |
|---|---|
| קרן פנסיה (מקיפה/כללית) | חיסכון פנסיוני עיקרי + ביטוחי נכות/שארים מובנים |
| קופת גמל | חיסכון גמיש, כולל "קופת גמל להשקעה" |
| קרן השתלמות | חיסכון עם הטבת מס, נזיל אחרי 6 שנים |
| ביטוח מנהלים | פנסיה מבוססת פוליסת ביטוח |

**בתי השקעות/חברות מנהלות:** מגדל, הראל, כלל ביטוח, מנורה מבטחים, הפניקס,
מיטב דש, אלטשולר שחם, אינפיניטי, ילין לפידות, More.

**רגולטור:** רשות שוק ההון, ביטוח וחיסכון.

**מקור מידע מרוכז:** אתר **"הר הביטוח"** (gov.il) — מרכז את כל מוצרי
הפנסיה/גמל/השתלמות/ביטוח של האזרח במקום אחד. אין API פתוח, אבל אפשר
להוציא דוח/PDF ולהזין ידנית — זו הדרך המומלצת לשלב הראשון של הפרויקט.

## 3. ביטוח

**חברות עיקריות:** הראל, מגדל, כלל ביטוח, הפניקס, מנורה מבטחים, איילון,
הכשרה, שירביט, ליברה, AIG ישיר, שלמה ביטוח (ישירות, בלי סוכן).

**סוגי פוליסות רלוונטיים לבית:**
- בריאות/סיעוד — פרטי, שב"ן (משלים שיניים/בריאות דרך קופ"ח), סיעודי
- חיים — ריסק, ביטוחי מנהלים
- רכב — חובה (סטטוטורי) + מקיף/צד ג' בלבד
- דירה — מבנה + תכולה
- נסיעות לחו"ל

**קופות חולים** (כללית/מכבי/מאוחדת/לאומית) הן שכבה נפרדת — ביטוח בריאות
ממלכתי + שב"ן, לא "ביטוח" מסחרי, אבל יש להן חיוב חודשי שכדאי למפות.

**רגולטור:** רשות שוק ההון, ביטוח וחיסכון (כמו פנסיה/גמל). גם ביטוחים
מופיעים ב"הר הביטוח".

## 4. מנויים ותשתיות בית

- **סלולר:** פלאפון, סלקום, פרטנר, הוט מובייל, גולן טלקום, רמי לוי
  תקשורת, 019, We
- **טלוויזיה/סטרימינג:** יס, הוט, נטפליקס וכו'
- **אינטרנט:** בזק, הוט, פרטנר
- **עירייה/ממשלה:** ארנונה, מים (תאגיד מים מקומי), חשמל (חח"י), גז

## 5. גופים ממשלתיים רלוונטיים

- **בנק ישראל** — בנקים, כרטיסי אשראי, Open Banking
- **רשות שוק ההון, ביטוח וחיסכון** — ביטוח, פנסיה, גמל, השתלמות
- **המוסד לביטוח לאומי** — ביטוח לאומי (נפרד לגמרי מהביטוחים הפרטיים)

## איך שואבים נתונים בפועל

1. **הזנה ידנית + העלאת קבצים (השלב הנוכחי בפרויקט)** — הכי בטוח, לא דורש
   אחסון סיסמאות. מקור נהדר: ייצוא מ"הר הביטוח" + דפי חשבון/הוראות קבע
   מהבנק.
2. **Open Banking API רשמי** — דורש רישוי כ"גוף מורשה", לא רלוונטי לפרויקט
   פרטי.
3. **Scraping לא רשמי** (למשל הספרייה הקהילתית `israeli-bank-scrapers`) —
   אפשרי בעתיד לבנקים/אשראי, אבל דורש אחסון credentials מאובטח **מקומית
   בלבד**, ולא בריפו. שלב עתידי, בכפוף להחלטה מפורשת.

## איך זה מתורגם למודל הנתונים

- **Provider** — מוסד (בנק/חברת ביטוח/בית השקעות/ספק תקשורת/רשות
  מקומית), מתוך `data/providers.seed.json` — מידע ציבורי, לא רגיש.
- **Category** — סוג הפריט (עו"ש, אשראי, פנסיה, גמל, השתלמות, ביטוח
  בריאות/חיים/רכב/דירה/נסיעות, קופת חולים, סלולר, טלוויזיה, אינטרנט,
  ארנונה/מים/חשמל/גז, אחר).
- **Item** — הפריט הקונקרטי של משק הבית (חשבון/פוליסה/מנוי): ספק,
  קטגוריה, מספר חשבון/פוליסה, סכום חודשי, סטטוס טיוב (`draft` /
  `verified` / `needs_review`), מסמכים מצורפים. **כל הנתונים האמיתיים
  האלה נשמרים מקומית בלבד (`data/local/`), ולא נכנסים ל-git.**
